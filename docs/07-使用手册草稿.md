# teamlab-web-mvp 使用手册

## 如何打开

1. 拿到项目文件夹
2. 起一个本地服务器（**推荐**，摄像头和 Canvas 后处理需要）

```bash
cd teamlab-web-mvp
python3 -m http.server 3000
# 浏览器访问 http://localhost:3000
```

3. 看到黑色背景上出现彩色光点，就是成功了

> 直接双击 `index.html` 打开可能因浏览器安全策略导致摄像头权限或 Bloom 后处理受限。

> 如果打开后是空白，检查网络能否访问 `cdnjs.cloudflare.com`（p5.js 和 MediaPipe 均从 CDN 加载）。

## 如何互动

### 桌面端（摄像头体感 — MVP-2 核心体验）

- 允许浏览器使用摄像头（首次会弹权限请求）
- 举起一只手，把食指伸到摄像头视野内
- 右下角会出现 160×120 的小预览窗，看到**绿色手骨架 + 红色食指尖标记** = 识别成功
- 移动食指，光点会被指尖轻轻推开，像用手指搅动水面
- 双手靠近：粒子被吸引至双手中点，距离越近吸引力越强
- 单手悬停 0.8 秒：自动产生淡青色涟漪（无需点击）
- 手移出画面 2 秒后，自动回退到鼠标控制

### 桌面端（鼠标 — 体感不可用时的 fallback）

- 随便动鼠标，光点会被轻轻推开
- 推得快，散得开；停得久，慢慢合
- **点击画面**：产生淡青色涟漪，像投石入水
- 静止观察：光点之间有极细的丝线相连，形成粉、青、金三色交织的光网

### 扫描涂鸦生成角色（MVP-4）

- 用黑色马克笔在纸上画鱼/花/任何连续线条
- 把画对准摄像头，确保在画面中心区域
- 移开手，按 **空格键**
- 3 秒内生成游动的粒子角色，沿你画的轮廓移动
- 角色会被手/鼠标排斥、被涟漪击散、受流动场影响

### 手机/平板

- 不支持摄像头体感（性能考虑），仅支持触摸
- 单指滑动 = 鼠标移动效果
- 单指点击 = 产生涟漪
- 建议横屏观看，视野更宽

## 性能提示

**如果你的电脑/手机有点老**

不用做任何操作，程序自动检测并降级：
- 手机自动从 1500 粒子降到 500
- 帧率 < 30 时自动砍掉 20% 粒子
- 帧率持续过低时自动关闭 Bloom、降低流动场分辨率
- 右下角显示实时 FPS：绿色 = 流畅，黄色 = 勉强，红色 = 在救你了

**手动调参数**

打开 `js/main.js`，顶部有多个配置对象：

```javascript
const CONFIG = {
  repelRadius: 100,      // 排斥半径
  repelStrength: 0.6,    // 排斥力度
  maxVelocity: 1.5,      // 粒子最快速度
  lerpFactor: 0.08,      // 回归原速的快慢
  // ...
};

const BLOOM_CONFIG = {
  enabled: true,
  scale: 4,              // 降采样倍率
  radius: 20,            // 模糊半径
  strength: 0.6,         // 叠加强度
};
```

改完刷新页面即生效，无需重新编译。

## 移动端适配说明

- 已禁用双指缩放（`user-scalable=no`），防止滑动时页面缩放
- 触摸事件和鼠标事件共享同一套逻辑，手感一致
- 移动端光晕少一层，减少绘制开销
- 某些安卓机型若卡顿，尝试用 Chrome（自带浏览器对 Canvas 优化较弱）

## 常见问题

**Q：为什么打开后全是黑的，没有光点？**
A：大概率是网络问题，p5.js CDN 没加载出来。刷新试试，或切稳定网络。

**Q：粒子会不会越来越多，最后卡死？**
A：不会。系统保持粒子总量恒定，死多少补多少，不会暴涨。

**Q：扫描涂鸦没反应？**
A：检查三点：① 是否通过 localhost 打开（file:// 会限制摄像头）② 画是否用了黑色粗线 ③ 画是否在画面中心区域。

**Q：可以保存为图片/视频吗？**
A：当前版本不支持。这是实时体验，不是导出工具。
