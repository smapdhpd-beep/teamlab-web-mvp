# 视觉调优记录

## 2026-06-17：Step 2 排斥手感调优

| 参数 | 旧值 | 新值 | 原因 | 测试设备 |
|------|------|------|------|----------|
| repelStrength | 2 | 0.6 | 力度过大，粒子像烟花般弹射，缺乏 teamLab 水流感 | 桌面端 |
| maxVelocity | 3 | 1.5 | 速度上限太高，封顶后仍飞太远 | 桌面端 |
| lerpFactor | 0.05 | 0.08 | 回归稍慢，高速粒子持续漂移过久 | 桌面端 |

**触发反馈**：用户说"现在粒子弹开的速度有点快，像烟花一样"
**预期手感**：鼠标靠近时粒子如水流被轻柔推开，停止后缓缓归位

## 2026-06-17：Step 3 发光升级调优

| 参数 | 旧值 | 新值 | 原因 | 测试设备 |
|------|------|------|------|----------|
| BG_ALPHA | 20 | 15 | 配合 ADD 发光效果，残影留更久更梦幻 | 桌面端 |
| 颜色格式 | `#FFB7C5` / `#00D2FF` / `#FFD700` | `[255,105,180]` / `[0,255,255]` / `[255,215,0]` | 提高饱和度，发光更鲜艳 | 桌面端 |
| 粒子形态 | 单层实心圆 | 三层光晕（外层α30/中层α80/核心α200） | teamLab 标志性弥散光球质感 | 桌面端 |
| 移动端绘制 | 同桌面 | 去掉外层（2层） | 减少 1/3 绘制开销 | 移动端 |

## 2026-06-17：Step 3 降曝调优（人眼不适反馈）

| 参数 | 旧值 | 新值 | 原因 | 测试设备 |
|------|------|------|------|----------|
| 外层光晕 | 存在（α30, size×4） | **去掉** | 三层叠加过曝，人眼不适 | 桌面端 |
| 中层 alpha | 80 | 40 | 降低弥散层亮度 | 桌面端 |
| 中层 size 倍率 | ×2 | ×2.5 | 补偿去掉外层后的弥散范围 | 桌面端 |
| 核心 alpha | 200 / 255 | 120 / 180 | 核心亮点降曝，靠近时从 180 起跳（非 255） | 桌面端 |
| 粒子 size 范围 | 2~6 | 1.5~4 | 整体光球更小更精致 | 桌面端 |
| BG_ALPHA | 15 | 18 | 拖尾稍短，减少持续叠加导致的过曝 | 桌面端 |

**触发反馈**：用户"粒子太亮了，人眼表示有点受不了"

## 2026-06-18：Step 6 吸引光晕调优（过曝 + 环纹 + 延迟反馈）

| 参数 | 旧值 | 新值 | 原因 | 测试设备 |
|------|------|------|------|----------|
| 光晕绘制方式 | 单圆 `circle(d=400, a=10)` | 三层同心圆（α6/4/2） | 硬边圆盘感，不像 teamLab 光雾 | 桌面端 |
| 光晕绘制方式 v2 | 三层同心圆 | **径向渐变** `createRadialGradient` | 同心圆在 ADD 下叠出环纹（奥运五环感） | 桌面端 |
| 光晕中心 alpha | 0.10 | **0.05 + 正弦呼吸**（0.6~1.0 波动） | 恒定叠加导致双手靠久过曝刺眼；呼吸脉动增加有机感 | 桌面端 |
| 光晕半径 | 200px | 280px | 与降低后的 alpha 平衡，保持可见但柔和 | 桌面端 |
| EMA 默认 α | 0.3 | **0.5** | 手控明显 lag 于鼠标，跟手感差 | 桌面端 |
| EMA 静止 α | 0.1 | **0.08** | 手静止时更稳，消除微抖 | 桌面端 |
| 静止判定阈值 | 3px / 5帧 | **2px / 3帧** | 更快进入深度平滑，减少静止时 jitter | 桌面端 |
| 快速移动直通 | 无 | **位移>20px 时 α=0.85** | 手快速挥动时几乎零滞后，接近鼠标响应 | 桌面端 |

**触发反馈**："双手靠近还是像个大圆盘，还一环套一环呢"、"手控时明显比鼠标反应要慢"、"双手靠在一起时间长了光晕就会变得很刺眼"

**关键决策**：ADD 模式下的光晕绝对不能用硬边几何图形叠加，必须用径向渐变实现数学平滑 falloff；长时间恒定叠加必然过曝，必须加呼吸波动或降低基础 alpha。
